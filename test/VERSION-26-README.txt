HFF WEBSITE VERSION 26

Admin navigation redesign:
- Edit HFF Website opens the HFF visual editor.
- Edit Hustle Website opens the Hustle homepage in Edit Mode.
- Clicking an active Hustle team carries Edit Mode into that team page.
- Clicking SCHEDULE on a Hustle team page opens Schedule Admin filtered to that team and season.
- Schedule Admin provides a Back to Team Page link.
- Operational tools remain directly accessible from Admin Dashboard/Admin navigation.
- Previously-run SQL migration files were removed from this clean package.
- No SQL update is required for Version 26.
